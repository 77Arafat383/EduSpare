Implement WebSockets

schedule Due in 2h priority_high High Priority person Assignee: Alex C.

description Description

We need to implement real-time bidirectional communication for the new live collaboration feature. This involves setting up Socket.io on the Node.js backend and integrating it with the React frontend.

Key requirements include handling initial connection handshakes securely, managing room assignments for active document sessions, and ensuring robust error handling for disconnects and reconnects. On the client side, we need a custom Redux middleware to dispatch socket events to the store seamlessly.
